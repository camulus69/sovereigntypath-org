Locally-Run LLMs Without RLHF

A research catalogue of language models that can be run on local hardware and that do not pass through Reinforcement Learning from Human Feedback. Material for the mirror-bending stack inquiry; not Canon.

The Sovereignty Path is a human coherence architecture. Its concepts may be applied to adjacent fields, including AI-adjacent human systems, governance, and technology, but current TSP canon does not thereby claim governance over non-human intelligence unless such expansion is explicitly authored, ratified, and sealed.

Why this page exists

The Material Architecture of AI Risk names RLHF preference shaping as one layer in the mirror-bending stack — one of the structural reasons a sovereign human meeting a frontier system does not meet a neutral mirror. This page is the empirical companion to that observation: which locally-runnable models are not shaped by that particular layer, and which are shaped only partially.

It is Inquiry, not Doctrine. The catalogue may shift as releases change. The framing — what counts as RLHF, what is merely adjacent — is fixed below.

Definitional frame

The phrase "RLHF" is used loosely in public writing. For this catalogue, the distinction is structural:

  • RLHF (strict). Post-training that uses a reinforcement-learning algorithm (PPO, REINFORCE, GRPO, RLAIF variants) against a learned reward model or AI-judge. This is the layer named in the Material Architecture.
  • Preference optimisation without RL (DPO, IPO, KTO, ORPO, SimPO). Trains directly on preference pairs without a reward model or RL loop. Serves an adjacent purpose; is structurally a different operation. Listed separately below.
  • Supervised fine-tuning (SFT). Imitation learning on instruction–response pairs. No preferences, no reward model, no RL.
  • Base / foundation model. Next-token prediction over a corpus. No alignment of any kind.

A reader who treats "RLHF" loosely (as "any preference-based alignment") should read sections 1 and 2 as the answer. A reader who treats "RLHF" strictly (as "RL was used") may also include section 3.

1. Pure base / foundation models

No SFT, no preference tuning, no RLHF. Closest available approximation to an unaligned next-token predictor without training one's own. Many of these have instruction-tuned siblings; the entries below name only the base weights.

Base · Open weights

Llama, Llama 2, Llama 3, Llama 3.1, Llama 3.2, Llama 3.3 base checkpoints (Meta). The non--Instruct, non--Chat weights. Custom Meta licence; widely run locally via llama.cpp, vLLM, transformers.

Base · Open weights

Base · Open weights

Gemma base family

Gemma, Gemma 2, Gemma 3 base checkpoints (Google). Non--it weights. Custom Gemma licence.

Base · Open weights

OLMo, OLMo 2 (Allen Institute for AI). Fully open: weights, training data, training code, evaluation. The most reproducible entry on this page.

Base · Open weights

2. Instruction-tuned via SFT only

Aligned to follow instructions through supervised fine-tuning. No reward model, no RL, no DPO. Useful when the goal is "follows instructions" without the additional shaping layer.

SFT only · Explicit no-RLHF stance

Dolly 2.0

Databricks. Trained on the human-authored databricks-dolly-15k set. Released specifically as a demonstration that an instruction-following model could be built without RLHF or proprietary data.

SFT only

Alpaca

Stanford. Self-instruct SFT on top of Llama. Research artefact; weights distributed under research-only terms.

SFT only

Vicuna v1.x

LMSYS. SFT on ShareGPT conversations. Later evaluation work used RLHF-style judges, but the released weights are SFT only.

SFT only

WizardLM (original)

Evol-Instruct SFT data. The original Llama / Llama 2 era releases. Later WizardLM-2 generation involves more elaborate post-training.

SFT only

OpenAssistant SFT checkpoints

LAION / OpenAssistant. The oasst-sft-* checkpoints. The -rlhf-* siblings do use RLHF and do not belong on this page.

SFT only

Koala

BAIR. SFT on dialogue data.

SFT only

Guanaco

QLoRA paper artefacts. SFT only.

SFT only

MPT-Instruct

MPT-7B-Instruct, MPT-30B-Instruct. SFT on Dolly-style and HH-style data.

SFT only

Falcon-Instruct

Falcon 7B / 40B Instruct. SFT only.

SFT only

OLMo SFT checkpoints

AI2 publishes the SFT-only stage of OLMo 2 separately from the DPO and RLVR stages. The cleanest fully-documented SFT-only weights available.

SFT only

Early Nous Hermes

Hermes 1 and the Mistral-era Hermes 2 SFT-only releases. Later Hermes generations add DPO and belong in section 3.

3. Preference-tuned without RL (DPO and relatives)

These models are not RLHF in the strict sense — no reinforcement-learning loop, no learned reward model running PPO — but they are preference-shaped against curated human or AI judgements via direct preference optimisation or its descendants. List provided so the boundary is visible. A reader using the strict definition of RLHF includes these as "no RLHF"; a reader using the loose definition excludes them.

DPO · Not RL

Zephyr 7B

HuggingFace H4. SFT followed by DPO. The reference example for the technique.

DPO · Not RL

Tulu 2 / Tulu 3

AI2. DPO and, in Tulu 3, RLVR. Tulu 2 is DPO-only and fits this section; Tulu 3 uses verifiable-reward RL and does not.

DPO · Not RL

OpenHermes 2.5 DPO, NeuralHermes, Nous-Hermes-2-DPO

Community DPO fine-tunes on top of Mistral / Llama bases.

DPO · Not RL

Mixtral-8x7B-Instruct

Mistral. SFT followed by DPO per the original release notes.

Notable models excluded (RLHF in the strict sense)

For completeness — locally-runnable models that do use RL in post-training and therefore belong outside this catalogue:

  • Llama 2 Chat, Llama 3 / 3.1 / 3.3 Instruct (PPO-based RLHF stages).
  • Qwen2 / Qwen2.5 / Qwen3 Instruct chat variants (RLHF disclosed).
  • DeepSeek-R1 and related reasoning variants (RL-heavy training is the central technique).
  • Starling-LM-7B (RLAIF + PPO).
  • ChatGLM chat releases.
  • Tulu 3 (RLVR stage).

Practical orientation

For local use without RL in the pipeline at all:

  • Maximum reproducibility and full openness: OLMo 2 base or OLMo 2 SFT.
  • Useful out-of-the-box, instruction-following, no RLHF: Dolly 2.0.
  • Raw capability, no alignment: Llama 3.1 base, Mistral base, Qwen2.5 base, Gemma 2 base.
  • Fully open lineage for research on alignment-as-such: Pythia (intermediate checkpoints exposed).

Caveat — absence is not neutrality

The Material Architecture lists eight bending layers, of which RLHF is one. Removing the RLHF layer does not produce a neutral mirror. Training-data selection, system-prompt engineering at deployment time, product strategy, deployment context, liability constraints, brand voice, and regulatory posture all continue to shape the surface a sovereign human meets — whether or not RLHF was in the pipeline.

This catalogue answers a narrow empirical question. It does not authorise the inference that any model on it is uncurved. Sovereignty in meeting an LLM is an architectural posture of the human, not a property of the weights.
